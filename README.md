# Hero Quest

Interactive iPad activities (voice, sounds, games) and printable daily worksheets for maths and English practice.

- **App:** open `index.html` on the site root. On an iPad: Safari → Share → Add to Home Screen, and turn off the silent switch.
- **Print:** open `print/index.html`, pick a day, press Print. A4, 100%, double-sided (flip on long edge), Background graphics on, Margins none.
- **Develop:** `npm install`, `npm start` (serves on http://localhost:4173), `npm test`.
- **Add content:** see `CLAUDE.md`.

Served by GitHub Pages from the `main` branch (root).
