# Legacy worksheets

Standalone printable worksheets made before the data-driven print page existed. They still open and print on their own
(they are single HTML files) but they use the older "4 pages per quest" layout.

Worth porting into `data/units/` + `print/print.js` when needed:

- `math-times-tables.html`: ten times-table sets (pick one in the dropdown): Groups Power, Twos/Fives/Tens, Power of 3, 4, 6, 7, 8, 9, Table Master.
- `math-subtraction-back-through-10.html`: subtraction through ten.
- `math-addition-jump-through-10.html`, `english-quest-2-blend-bridge.html`: the 4-page originals of units that now exist in `data/units/`.
- `hero-quest-map.html`: the 20-stone map (print once, colour a stone per quest).
